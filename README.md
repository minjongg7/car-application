# 차량용 앱 — BMS로 차량을 지키고, 음성으로 가족을 돌보는 전기차 통합 앱

현대자동차그룹 차량용 앱 개발 공모전 출품작 · **Pleos Connect** (Android Automotive) 앱

BMS 데이터로 배터리 건강·예측 정비·V2L/V2G 전력을 관리하고, 장거리 여행에서는 운전자 피로와 아이·어르신의 휴식 시점을 판단해 차량이 먼저 휴게소를 제안하며 음성으로 가족을 돌봅니다.

## 주요 기능
| 화면 | 기능 |
|---|---|
| 🧭 내비 · 🛡 피로도 | 목적지 검색 → 경로·도착 배터리·경로상 휴게소/충전소 사전 점검 → Pleos 내비로 안내 / 주행 시간·속도 기반 피로도 단계와 휴게소 추천 |
| ⚡ Energy Hub | V2L 스마트 방전(출근용 최소 전력 잠금) · V2G 전력 거래 대시보드(캔들·거래량·RSI) |
| 🩺 Predictive Care | 차량 건강 점수 · 96셀 전압/온도 히트맵 · "3개월 내 부품 다운타임 확률" 예측 정비 리포트 |
| 👨‍👩‍👧 Family Care | 나이별 음성 콘텐츠 · 여정 진행 지도("할머니 집까지 사과 3개 남았어!") · 음성 놀이(끝말잇기·스무고개·지역 퀴즈) · 동승자 맞춤 휴식 추천("다음 휴게소에서 쉬어갈까요?" → 대답하면 내비에 경유지 추가) |

## 사용한 Pleos SDK
| SDK | 버전 | 용도 |
|---|---|---|
| Vehicle | 2.3.2 | 배터리 잔량·용량·전비·주행가능거리·트립 주행 시간·기어·브레이크액 |
| NaviHelper | 3.0.5 | 경로 요청·경유지 추가·남은 거리/시간·턴바이턴 |
| TextToSpeech | 3.3.1 | 안내·콘텐츠·놀이 음성 |
| SpeechToText | 3.3.1 | 휴식 질문·음성 놀이 대답 인식 |

## 프로젝트 구조
- `app` — 내비게이션 · 피로도 가드
- `core` — 차량 신호 허브 · 공용 UI · 여정 공유(TripBridge)
- `feature-family` — Family Care
- `feature-energy` — Energy Hub
- `feature-care` — Predictive Care

## 실행 방법
1. Android Studio로 이 저장소 폴더를 열고 Gradle Sync
2. Pleos Connect Emulator (API 34) 선택 → ▶ Run
3. APK는 [Releases](../../releases)에서 받을 수 있습니다.

> 셀 단위 BMS·V2G 시세·휴게소 편의시설은 공개 SDK에 없어 시연용 데이터이며, 화면에 '데모 데이터'로 표시됩니다.
